## ✨ Features

- 🎙️ **Push-to-Talk Voice** – Hold to speak, release to send
- 👑 **Host / Join Model** – One person hosts a channel, others join
- 📡 **Real-time Communication** – Low-latency voice transmission
- 👥 **Multi-User Support** – Multiple users can join the same channel
- 📱 **Mobile Friendly** – Works on both desktop and mobile browsers
- 🔌 **No App Store Required** – Runs entirely in a web browser
- 🌐 **Works Anywhere** – Any network, any device with a browser
- ⚡ **Free & Open Source** – No subscriptions or hidden fees

## 🚀 Quick Start

1. **Open the app:** [https://vokitoki-lbp0.onrender.com](https://vokitoki-lbp0.onrender.com)

2. **Choose your mode:**
   - **👑 Host** – Create a channel and share the channel ID
   - **🔗 Join** – Enter a channel ID to connect

3. **Start talking!**
   - Press and hold the **🎤 HOLD TO TALK** button
   - Speak into your microphone
   - Release to send

## 🎮 How to Use

### Step 1: Open the App
Open the URL in any modern browser (Chrome, Edge, Firefox, Safari) on your phone or computer.

### Step 2: Choose Your Mode

| Mode | What It Does |
| :--- | :--- |
| **👑 Host** | Creates a new channel. You'll get a channel ID to share with others. |
| **🔗 Join** | Connects to an existing channel using a channel ID. |

### Step 3: Share the Channel ID
- If you're the **Host**, share the channel ID with others
- Others enter that ID in the **Join** mode

### Step 4: Start Talking
- **Press and hold** the large green **🎤 HOLD TO TALK** button
- **Speak** into your microphone
- **Release** the button to send your voice

### Step 5: See Who's Online
- The user list shows everyone in your channel
- 👑 = Channel Host
- 📱 = Other User
- **You** = You
